# Roadmap

## Jour 1 - Socle projet

- Creer la structure du depot.
- Initialiser Git.
- Ajouter la documentation de depart.
- Definir l'architecture cible.
- Verifier que le dossier projet est propre.

## Jour 2 - Environnement local

- Installer Python et les dependances.
- Configurer l'environnement virtuel.
- Valider les premiers tests.

## Jour 3 - Ingestion Adzuna

- Comprendre l'API Adzuna.
- Extraire les premieres offres.
- Stocker un exemple Bronze local.

## Jour 4 - Ingestion The Muse

- Comprendre l'API The Muse.
- Harmoniser la collecte multi-sources.

## Jours suivants

- Azure Data Lake Storage Gen2.
- Transformations Bronze vers Silver avec PySpark.
- Transformations Silver vers Gold avec PySpark.
- Chargement PostgreSQL.
- Airflow.
- Qualite des donnees.
- FastAPI.
- Streamlit.
- Recommandations.
- Docker.
- Documentation finale et preparation soutenance.

## Sprint final 3 heures

Priorite 1 : obtenir une demo locale executable avec PySpark, API et dashboard.

Priorite 2 : lancer Docker Compose si Docker Desktop est disponible.

Priorite 3 : preparer le discours de soutenance avec les compromis assumés : source scraping optionnelle, donnees d'exemple si les APIs ne sont pas disponibles, architecture Azure cible documentee.
